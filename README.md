# Muhammad Hasnain - Portfolio

Next.js 14 (App Router), plain CSS, no backend.

## Run
```bash
npm install
npm run dev      # http://localhost:3000
npm run build && npm start
```

## Edit content
All text lives in `lib/data.js` (profile, projects, skills, education).
Colors are CSS variables at the top of `app/globals.css`.
CV file: `public/Muhammad_Hasnain_CV.pdf`.

## Deploy
Push to GitHub and import into Vercel (zero config).
